# Шифр Цезаря з ключовим словом

Лабораторна робота № 1 з дисципліни «Технології захисту інформації», варіант 1:
шифрування і розшифрування вмісту файлу за методом Цезаря з ключовим словом.

## Алгоритм

Ключ складається з числа зсуву `k` (0 ≤ k ≤ n−1) та ключового слова. Під рядком
відкритого алфавіту, починаючи з позиції `k`, записується ключове слово без
повторних літер, після нього — решта літер алфавіту в природному порядку;
заповнення циклічне. Утворений рядок є шифрувальним алфавітом: символ на
позиції j замінює символ відкритого алфавіту з тією ж позицією.

Приклад: `k = 5`, ключове слово `CRYPTO`

```
Відкритий алфавіт:    ABCDEFGHIJKLMNOPQRSTUVWXYZ
Шифрувальний алфавіт: UVWXZCRYPTOABDEFGHIJKLMNQS
```

## Запуск

```
javac -encoding UTF-8 -d out src/cipher/*.java
java -cp out cipher.Main
```

Меню програми дозволяє задати ключ, зашифрувати чи розшифрувати введений з
клавіатури текст, а також вміст файлу. Символи поза алфавітом (пробіли,
розділові знаки, цифри) переносяться без змін, регістр літер зберігається.

## Структура

| Клас | Призначення |
|---|---|
| `Alphabet` | алфавіт шифру, перевірка на повтори |
| `KeywordCaesarKey` | побудова шифрувального алфавіту за ключем |
| `KeywordCaesarCipher` | пряме та зворотне перетворення тексту |
| `TextFileService` | читання та запис текстових файлів |
| `ConsoleUi` | меню та діалог з користувачем |
| `CipherException` | передбачувані помилки роботи програми |
| `Main` | точка входу, початкові параметри |
